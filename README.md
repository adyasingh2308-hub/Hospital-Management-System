# Hospital Management System

## Project Overview

The Hospital Management System is a Python-based project designed to manage basic hospital operations efficiently. It helps organize patient information and other hospital-related records through a simple, menu-driven interface.

This project was developed as part of my Python programming coursework to understand the practical application of programming concepts.

## Objectives

* To maintain patient records.
* To organize hospital-related information.
* To simplify basic hospital management tasks.
* To apply Python programming concepts to a real-world problem.

## Features

* Add and manage patient details.
* View stored patient records.
* Manage hospital information through a menu-driven system.
* Perform basic record management operations.

## How to Run the Project

1. Download or clone this repository.

2. Open the project folder in Visual Studio Code.

3. Make sure Python is installed on your computer.

4. Open the terminal in the project folder.

5. Run the following command:

   ```bash
   python main.py
   ```

6. Follow the instructions displayed in the terminal.
